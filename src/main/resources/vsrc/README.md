# Approximate Multiplier Library

This directory contains approximate multiplier circuits from the EvoApprox library, organized by bit-width and signedness. Each class contains Pareto-optimal sub-sets selected with respect to power and a chosen error metric.

## Directory Structure

```
vsrc/
├── 8x8_unsigned/
├── 8x8_signed/
├── 11x11_unsigned/
├── 12x12_unsigned/
├── 12x12_signed/
├── 16x16_unsigned/
└── 16x16_signed/
    └── pareto_pwr_{ep,mae,mre,mse,wce}/
```

Each sub-directory holds Verilog (`.v`) and C (`.c`) model files for every circuit in that Pareto front.

### Error Metric Definitions

| Metric | Description |
|--------|-------------|
| **MAE%** | Mean Absolute Error (relative, %) |
| **WCE%** | Worst-Case Error (relative, %) |
| **EP%** | Error Probability (%) |
| **MRE%** | Mean Relative Error (%) |
| **MSE** | Mean Square Error |
